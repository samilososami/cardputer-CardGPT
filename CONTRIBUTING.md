# Contribuir a CardGPT

Gracias por ayudar a mejorar CardGPT. Mantén los cambios pequeños, documentados y centrados en el Cardputer ADV.

1. Describe el problema o propuesta en una issue, sin secretos ni datos de cuentas.
2. Trabaja en una rama y comprueba la compilación afectada.
3. Para el flasher, ejecuta `npm test` y `npm run build` en `web/flasher`.
4. Para firmware, ejecuta `bash scripts/build.sh` y documenta qué probaste realmente en el hardware. Una compilación no equivale a una prueba física.
5. Abre una pull request con propósito, cambios, pruebas y limitaciones.

No alteres la paleta aprobada ni reincorpores audio sin discutirlo antes. Preserva M5Launcher, NVS y los firmwares ajenos durante cualquier prueba. No incluyas backups, tokens, archivos `.env`, cachés o volcados de flash.
