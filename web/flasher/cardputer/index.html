Antes de darle a instalar.

    
¿Necesito un launcher o preparar el dispositivo?
No. El instalador funciona desde cero y sustituye el firmware que hubiera antes. Incluye su propio arranque, organiza la memoria y carga CardGPT. No exige que exista ninguna instalación anterior.

    
¿Se pierde la sesión al reinstalar?
Sí. Este instalador siempre borra toda la flash, incluida la Wi-Fi, la sesión y los ajustes. Tendrás que repetir la configuración inicial. Durante el uso normal, apagar o reiniciar no borra esos datos.

    
¿Y si ya tengo otros firmwares instalados?
Se eliminarán también, incluido cualquier launcher. Haz una copia de lo importante antes de continuar. La web pide una casilla de aceptación y una segunda confirmación antes de borrar.

    
¿Puedo instalar el archivo con otra herramienta?
Sí. El archivo de esta publicación es una imagen completa de 8.388.608 bytes para ESP32-S3 y se escribe desde 0x0, después de borrar toda la flash. No lo confundas con el antiguo binario de aplicación de 1.588.480 bytes: no son intercambiables. Comprueba siempre el SHA-256.

    
¿Necesito una tarjeta SD o una API key?
No necesitas microSD para instalar ni usar CardGPT. La vinculación usa el inicio de sesión por dispositivo de Codex, no una API key introducida en esta web. El acceso, los modelos y la cuota dependen de tu cuenta.

    
¿Qué pasa si se interrumpe la instalación?
El dispositivo puede quedarse sin un firmware arrancable. Entra en modo descarga con G0, reconecta y repite la instalación completa. La web no modifica eFuses y rechaza chips con Secure Boot o cifrado configurado. No fuerces el borrado de un dispositivo protegido.

    
¿Es una aplicación oficial de OpenAI?
No. CardGPT es un proyecto independiente de Sami González Kamel, sin afiliación con OpenAI, ChatGPT ni M5Stack. El servicio utilizado puede cambiar y dejar de ser compatible.
