Antes de darle a instalar.

    
¿Necesito M5Launcher?
No. Si está instalado, la web lo conserva y añade CardGPT como una app más. Si no está, ofrece una instalación completa e independiente. No tienes que preparar una partición llamada CardGPT de antemano.

    
¿Se pierde la sesión al reinstalar?
Al actualizar CardGPT dentro de M5Launcher se conserva NVS, incluida la configuración de CardGPT. Una instalación limpia sí borra Wi-Fi, sesión y ajustes, y se ofrece únicamente cuando no se detecta un M5Launcher compatible.

    
¿Y si ya tengo otros firmwares instalados?
Se conservan. El instalador usa una ranura CardGPT existente o espacio realmente libre. Si no hay hueco, cancela sin sustituir otra aplicación y te pide liberar espacio desde M5Launcher.

    
¿Puedo instalar el archivo con otra herramienta?
Sí. CardGPT.bin es la aplicación de 1.588.480 bytes para instalar desde M5Launcher. CardGPT-full.bin es la imagen completa de 8 MiB para escribir desde 0x0 tras borrar la flash. No son intercambiables; comprueba siempre el SHA-256.

    
¿Necesito una tarjeta SD o una API key?
No necesitas microSD para instalar ni usar CardGPT. La vinculación usa el inicio de sesión por dispositivo de Codex, no una API key introducida en esta web. El acceso, los modelos y la cuota dependen de tu cuenta.

    
¿Qué pasa si se interrumpe la instalación?
En modo M5Launcher, primero se escribe y verifica CardGPT y solo después se registra su nueva partición; el launcher y las demás apps no se escriben. En instalación limpia, una interrupción puede dejar el equipo sin arranque: entra con G0 y repite. La web no modifica eFuses.

    
¿Es una aplicación oficial de OpenAI?
No. CardGPT es un proyecto independiente de Sami González Kamel, sin afiliación con OpenAI, ChatGPT ni M5Stack. El servicio utilizado puede cambiar y dejar de ser compatible.
