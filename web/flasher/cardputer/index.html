Prepara el cable.
Y poco más.
La instalación directa se realiza en tu navegador. No hay que enviar credenciales a esta web.
  1. Abre un navegador compatible.
    Chrome, Edge u otro Chromium de escritorio con Web Serial, desde esta página HTTPS. En móvil, Safari o Firefox utiliza la descarga.
  2. Conecta un cable USB de datos.
    Cierra monitores serie, IDEs u otras pestañas que tengan abierto el puerto. Si no aparece, comprueba el cable y los permisos del sistema.
  3. Selecciona el puerto del Cardputer.
    Si no conecta, entra en modo descarga: mantén pulsado el botón G0 al conectar o reiniciar el dispositivo y suéltalo después. Vuelve a intentarlo.
  4. Revisa y confirma.
    Si la tabla es compatible, se habilita la instalación. No desconectes ni cierres la pestaña mientras se escribe y verifica.


Antes de darle a instalar.
¿Se borran M5Launcher o mis credenciales?
El actualizador escribe únicamente la partición de aplicación identificada como CardGPT. No ejecuta un borrado completo ni escribe NVS. La primera instalación se gestiona desde M5Launcher; revisa allí qué espacio vas a usar y haz una copia de seguridad.
¿Por qué bloquea mi tabla de particiones?
Puede faltar una partición llamada CardGPT, tener un tamaño insuficiente o una distribución no válida para este procedimiento. No fuerces una dirección de memoria. Instala primero desde M5Launcher y consulta el registro técnico para conocer la causa.
¿Necesito una tarjeta SD o una API key?
CardGPT no necesita una microSD para funcionar y usa el inicio de sesión por dispositivo de Codex, no una API key introducida en esta web. El acceso, los modelos y la cuota dependen de tu cuenta. La transferencia inicial por M5Launcher depende del método elegido.
¿Qué pasa si se interrumpe la escritura?
La aplicación CardGPT puede quedar incompleta. M5Launcher y el bootloader no se escriben en este proceso. Reconecta en modo descarga, comprueba el cable y repite la instalación. No desconectes el dispositivo voluntariamente durante la escritura.
¿Es una aplicación oficial de OpenAI?
No. CardGPT es un proyecto independiente de Sami González Kamel, sin afiliación con OpenAI, ChatGPT ni M5Stack. El servicio utilizado puede cambiar y dejar de ser compatible.
